# 🏃‍♂️ Metro Runner India

A 2D endless runner web game inspired by Subway Surfers, built using HTML, CSS, and JavaScript.

## 🎮 Live Demo
Play the game live here: [Metro Runner India](https://2025akshat-lang.github.io/Metro-Runner-India/)

## 🕹️ Controls
* **Arrow Keys / WASD**: Move player
* **Spacebar**: Jump / Action

## 🛠️ Tech Stack
* **HTML5** (Canvas & Structure)
* **CSS3** (Styling)
* **JavaScript** (Game Logic & Physics)
